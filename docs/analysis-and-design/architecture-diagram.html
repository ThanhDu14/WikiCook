4Pipe-and-filter

Dữ liệu chảy qua một chuỗi filter độc lập. Đầu ra của filter trước là đầu vào của filter sau.

a) Pipeline RAG của AI Weekly Meal Planner (spec 031)

INPUT

Hồ sơ người dùng

Dị ứng, kiểu ăn, thời gian nấu, số bữa

FILTER 1

Lọc hard rule

SQL: dị ứng, loại trừ, PUBLISHED, hợp bữa

FILTER 2

Truy hồi top-K

pgvector trên recipe_embeddings

FILTER 3

LLM xếp ô

Gemini Flash, JSON mode

FILTER 4

Validate

Kiểm từng pick; JSON hỏng → retry 1 lần

OUTPUT

Draft kế hoạch tuần

Trả về client để xác nhận

FILTER 5

Fallback greedy

Tất định, ≤ 2 s

Chạy thay cho filter 3–4 khi AI lỗi, quá 60 s hoặc hết hạn mức ngày.

INPUT

FILTER

FILTER

JWT authentication

Giải mã token → SecurityContext

FILTER

Authorization (RBAC)

Kiểm role

OUTPUT
